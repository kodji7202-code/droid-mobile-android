# Terms-of-service note

Droid Mobile is an unofficial client. It is not affiliated with, endorsed by, or connected
to Factory.

- Only public, supported interfaces are used: the official, Apache-2.0 licensed
  `@factory/droid-sdk` and the user's own `droid daemon`. No non-public APIs, no
  OAuth/WorkOS reuse, no `unstable.*` daemon APIs, no relay endpoints.
- No Factory trademarks are used in the app icon, store listing or About text.
- Login uses the user's own Factory API key (`fk-...`), stored in Android Keystore-backed
  storage.
